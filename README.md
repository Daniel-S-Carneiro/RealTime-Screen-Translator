# RealTime-Screen-Translator

A powerful, lightweight, and universal real-time screen translation tool for Windows. It captures text from any part of your screen using advanced OCR (Optical Character Recognition) and instantly translates it into over 80 languages. Perfect for translating video games, images, documents, and non-copyable text in real time.

## 🌟 Features

- **Universal Screen Capture:** Translate anything visible on your screen with a simple selection box.
- **High-Accuracy OCR:** Powered by robust text recognition engines to detect text under various backgrounds and fonts.
- **80+ Languages Supported:** Instant translation across a vast array of global languages.
- **Seamless UI Overlay:** Designed to be clean, intuitive, and non-intrusive while you play or work.
- **High-DPI Aware:** Crisp and sharp text rendering on modern high-resolution displays (1080p, 2K, 4K).
- **Fully Automated Installer:** Simple setup and complete uninstaller with Windows Start Menu and Desktop shortcuts.

## 🚀 Getting Started

### Prerequisites
- Windows 10 or 11 (64-bit)

### Installation
1. Download the latest installer `TradutorGameplay_Setup.exe` from the Releases section.
2. Run the installer (Administrator privileges required to install to Program Files).
3. Follow the setup wizard and launch the application.

## 🛠️ Technology Stack

- **Backend:** Python
- **GUI Framework:** PySide6 / Qt
- **OCR Engine:** EasyOCR / OpenCV
- **Packaging:** PyInstaller
- **Installer System:** NSIS (Nullsoft Scriptable Install System)
